# 🧑‍💻 Портфолио Михаила Сивоконь

Добро пожаловать в мой персональный сайт-разработчика!
Это интерактивное портфолио, созданное с нуля на базе **React**, **Vite** и **Tailwind CSS**, демонстрирующее мои навыки, опыт, проекты и контакты.

---

## 🚀 Технологии

* ⚛️ **React 18+**
* ⚡ **Vite** — мгновенная сборка и разработка
* 🎨 **Tailwind CSS** — utility-first стилизация
* 💡 **FontAwesome / Material Icons**
* 🧱 Адаптивная вёрстка, переиспользуемые компоненты
* 🧠 Чистая архитектура, модульность

---

## 📁 Структура проекта

```
src/
├── assets/            # Фото, иконки, изображения
├── components/
│   ├── tabs/          # Обо мне, Опыт, Стек, Проекты, Контакты
│   └── ui/            # Общие UI-элементы (SectionTitle и др.)
├── layout/            # Layout и навигация
├── pages/             # Главная страница
└── App.jsx            # Точка входа
```

## 📦 Быстрый старт

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/s1vo/portfolio.git
cd portfolio

# 2. Установите зависимости
npm install

# 3. Запустите в режиме разработки
npm run dev
```
